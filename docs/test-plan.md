# Тест-план aqa-juice-shop

## Сценарий-ядро
Регистрация → поиск товара → корзина → оформление заказа → проверка заказа через API.

## UI-тесты

| ID   | Название              | Шаги                                          | Ожидаемый результат            | Тег        |
|------|-----------------------|-----------------------------------------------|--------------------------------|------------|
| UI-1 | Поиск существующего товара | Открыть главную, ввести «apple», нажать поиск | Найден хотя бы один товар | smoke      |
| UI-2 | Пустой поиск          | Открыть поиск, нажать кнопку без ввода текста | Подсказка или пустой результат | regression |
